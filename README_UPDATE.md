# Detector v0.5.6 — Presence Evidence

Derived from existing v0.5.4, not the unused v0.5.5 distance-normalization build.

Stop Monitoring, back up your unpacked extension, update the same extension folder and reload it from `chrome://extensions` only **after Oracle Stage 5E is activated**. Enter your previously assigned Oracle key if Chrome starts with empty extension storage. The assigned UK seconds and key-only identification must remain unchanged.

- Keeps every warehouse location/distance in the job ID.
- Continues normal job observation first; the separate `/presence` request records appearance, missing scans, changed fields and returns without delaying receiver signals.
- Never opens job cards; never bypasses CAPTCHA or restrictions.
- Evidence upload `202` means stored for processing, **not** a receiver acknowledgement.
- When a page cannot be confirmed complete, missing cards are not classified as absent. This favors avoiding false signal floods over asserting certainty.
